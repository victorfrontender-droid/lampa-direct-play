# Direct Play для Lampa

Кнопка «Смотреть» в карточке фильма или сериала:

- продолжает просмотр: тот же торрент, та же серия, с того же места
- если смотреть ещё нечего, сразу открывает единственный источник, без меню выбора

## Зачем

В новых версиях Lampa при включённых плагинах кнопка «Смотреть» всегда показывает меню «Источник», даже если в нём один пункт «Торренты», а потом приходится заново искать торрент и серию.

## Что делает

### Продолжение просмотра

1. Запоминает для каждого фильма и сериала торрент (magnet-ссылку) и серию, которую вы запустили или смотрели при закрытии плеера
2. По кнопке «Смотреть» открывает тот же торрент штатным способом Lampa и сам выбирает эту серию
3. Если серия досмотрена на 90% и больше, выбирает следующую
4. Время, озвучку, плейлист серий Lampa подставляет сама, как при обычном запуске
5. Если такой серии в раздаче больше нет, просто показывает список файлов

**Долгое нажатие на «Смотреть»** — обычный выбор источника и торрента, без продолжения.

Хранится до 100 последних фильмов и сериалов, на каждом устройстве свой список.

### Сразу открывать единственный источник

1. Если запомненного просмотра нет и источник один, сразу открывает его без меню
2. Если источников несколько, меню показывается как обычно

Пункт «Добавить источник» (на Android) не считается источником.

## Установка

1. Откройте Лампу
2. `Настройки → Расширения / Плагины → Добавить плагин`
3. Вставьте:

```text
https://cdn.jsdelivr.net/gh/victorfrontender-droid/lampa-direct-play@main/direct-play.js
```

4. Перезапустите Лампу

Чтобы плагин подключился на всех устройствах, добавьте ссылку в свой профиль на сайте CUB: плагины аккаунта загружаются автоматически на всех устройствах, где выполнен вход.

## Проверка

1. Откройте карточку сериала, нажмите «Смотреть»: сразу откроется список торрентов
2. Выберите торрент и серию, посмотрите немного и закройте плеер
3. Вернитесь в карточку и снова нажмите «Смотреть»: откроется тот же торрент и запустится та же серия
4. Удерживайте «Смотреть»: откроется обычный выбор торрента

## Отладка

В консоли Лампы (DevTools) логи включаются так:

```js
Lampa.Storage.set('direct_play_debug', true)
```

Выключить:

```js
Lampa.Storage.set('direct_play_debug', false)
```

Префикс логов: `[Direct-Play]`

Сбросить все запомненные просмотры:

```js
Lampa.Storage.set('direct_play_resume', {})
```
